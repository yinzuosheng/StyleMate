# StyleMate 个人衣橱助手｜项目经历

- 基于 Streamlit 实现个人衣橱管理、图片识别、天气穿搭、场景调整和旅行规划；接入 OpenAI-compatible 多模态模型，并提供字段人工校正和无模型密钥时的手工录入降级。
- 设计基于当前衣橱候选 ID 的确定性搭配规则，确保推荐不虚构衣物；无衣橱时先返回通用知识方案，有衣橱时再追加库存匹配；天气失败时仍保留规则降级。
- 构建 BM25 + 向量召回 + Chroma + RRF 混合检索链路，在 60 条文档级离线用例上实现 Recall@5 95.00%、MRR@5 98.06%、nDCG@5 94.98%；该结果使用可复现离线 Embedding 配置，在线 Qwen3 Embedding 需单独评测。
- 设计有界 LangGraph Agent、结构化会话事实和 PendingAction 人在回路写操作；执行 181 条自动化回归测试，离线工具路由、写入保护和记忆事实召回通过率均为 1.0。
